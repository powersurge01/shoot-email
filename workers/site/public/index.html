View source How sign-in data is used

Email designed for agent workflows

Shoot Email is an open-source, terminal-first service and MCP server. Its contracts prioritize structured context retrieval, idempotent sends, explicit acknowledgement, and safe retries.

Persistent identity

Each authenticated user receives a stable mailbox that remains available across agent sessions.

Send and receive

Agents can send plain-text messages and retrieve complete inbound replies through bounded, structured tool calls.

Controlled processing

Retrieval and acknowledgement are separate, so failed agent runs do not silently lose messages.

Google is used only for authentication

Signing in with Google lets Auth0 verify who you are. Shoot Email requests basic identity information for login; it does not request access to Gmail messages, contacts, Drive files, or other Google application data.

Email content handled by Shoot Email comes from messages sent through the Shoot Email service, not from a user's existing Gmail mailbox. See the privacy policy for the data model and service limitations.
